### 1A. Dev Mode: Aim Trace Line (aimbot visualization)

**What:** When `show_hitboxes` is ON, draw a continuous 3D line from the player's eye to wherever their aim hits a hitbox. If no hit, draw a dim line to max range. Useful for debugging and future AI.

**Files:**
- `client/src/screens/playing/rendering.rs` — new `draw_aim_trace()` method
- `client/src/screens/playing.rs` — call it during 3D render pass

**Implementation:**

In `rendering.rs`, add to `impl PlayingState`:
```rust
pub(super) fn draw_aim_trace(&self) {
    use crate::weapons::combat::CombatEntity;

    let eye = self.position + vec3(0.0, 1.6, 0.0);
    let fwd = vec3(
        self.yaw.cos() * self.pitch.cos(),
        self.pitch.sin(),
        self.yaw.sin() * self.pitch.cos(),
    );

    let stats = self.weapons.active().stats();
    let range = stats.bullet_range;

    // find closest hit across all entities
    let mut closest: Option<(f32, crate::weapons::combat::HitZone)> = None;

    if let Some((zone, dist)) = self.target_dummy.ray_test(eye, fwd, range) {
        closest = Some((dist, zone));
    }
    for p in &self.other_players {
        if let Some((zone, dist)) = p.ray_test(eye, fwd, range) {
            let is_closer = closest.map_or(true, |(d, _)| dist < d);
            if is_closer {
                closest = Some((dist, zone));
            }
        }
    }

    let (end_point, color) = if let Some((dist, zone)) = closest {
        let hit_color = match zone {
            crate::weapons::combat::HitZone::Head => Color::from_rgba(255, 50, 50, 200),
            crate::weapons::combat::HitZone::Torso => Color::from_rgba(50, 255, 50, 200),
            crate::weapons::combat::HitZone::Limbs => Color::from_rgba(50, 150, 255, 200),
        };
        (eye + fwd * dist, hit_color)
    } else {
        (eye + fwd * range, Color::from_rgba(255, 255, 255, 40))
    };

    // draw the trace line (3 offset lines for thickness)
    let up = vec3(0.0, 1.0, 0.0);
    let side = fwd.cross(up).normalize() * 0.01;
    draw_line_3d(eye, end_point, color);
    draw_line_3d(eye + side, end_point + side, color);
    draw_line_3d(eye - side, end_point - side, color);

    // draw a small sphere at hit point
    if closest.is_some() {
        draw_sphere(end_point, 0.05, None, color);
    }
}
```

In `playing.rs`, after `self.draw_tracers();` (around line 452):
```rust
if self.dev_mode.show_hitboxes {
    self.draw_aim_trace();
}
```

```rust
// in simulate() or a new method, update sway
let is_moving = self.movement_state.is_moving();
let is_crouching = self.movement_state.is_crouching;
let sway_amount = if is_crouching { 0.3 } else if is_moving { 1.0 } else { 0.5 };

// sinusoidal sway using time

let sway_x = (time * 1.2).sin() * sway_amount;
```

## Phase 3: Billboard quad tracers with glow

### 3A. Upgrade tracers to billboarded quads

**What:** Replace the current 3-line `draw_line_3d` tracers with camera-facing quads that have a glow texture. Much more visually appealing.

**Files:**
- `client/src/screens/playing/rendering.rs` — rewrite `draw_tracers()`
- `client/src/weapons/effects.rs` — add glow texture loading or procedural generation
- Asset: create a simple 1D gradient texture (white center → transparent edges)

**Approach:**
1. For each tracer, compute a quad that always faces the camera (billboard)
2. Vertices: `tail - right*width`, `tail + right*width`, `head + right*width`, `head - right*width`
3. `right = normalize(cross(tracer_dir, camera_to_tracer))` — this makes it face the camera
4. Apply a glow texture (or use additive blending with a gradient)
5. Width tapers from head (thicker) to tail (thinner) for a comet-trail look

```rust
pub(super) fn draw_tracers(&self, camera_pos: Vec3) {
    for t in &self.tracers {
        let dir = t.end - t.start;
        let dist = dir.length();
        let dir_norm = dir.normalize();

        let head = t.start + dir * t.progress;
        let tail_t = (t.progress - t.tracer_length / dist).max(0.0);
        let tail = t.start + dir * tail_t;

        // billboard: always face camera
        let to_cam = (camera_pos - (head + tail) * 0.5).normalize();
        let right = dir_norm.cross(to_cam).normalize();

        let width = 0.04; // base width
        let alpha = (t.lifetime * 255.0).min(255.0) as u8;

        // head quad (brighter, wider)
        let v1 = tail - right * width * 0.5;
        let v2 = tail + right * width * 0.5;
        let v3 = head + right * width;
        let v4 = head - right * width;

        let color = Color::from_rgba(255, 220, 100, alpha);
        // draw as two triangles
        draw_triangle_3d(v1, v2, v3, color);
        draw_triangle_3d(v1, v3, v4, color);

        // glow pass (wider, more transparent)
        let glow_w = width * 3.0;
        let glow_alpha = (alpha as f32 * 0.3) as u8;
        let gv1 = tail - right * glow_w * 0.5;
        let gv2 = tail + right * glow_w * 0.5;
        let gv3 = head + right * glow_w;
        let gv4 = head - right * glow_w;
        let glow = Color::from_rgba(255, 180, 50, glow_alpha);
        draw_triangle_3d(gv1, gv2, gv3, glow);
        draw_triangle_3d(gv1, gv3, gv4, glow);
    }
}
```

Note: Need to pass `camera_pos` to `draw_tracers()`. Get it from the camera struct in the render function.

**File:** `client/src/weapons/combat.rs`

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum EntityKind {
    TargetDummy,
    Player,
    MovingTarget,

pub trait CombatEntity {
```

```rust
pub struct Bot {
```
